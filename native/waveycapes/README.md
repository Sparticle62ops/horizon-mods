# Wavey Capes (Horizon native port)

Exact 1:1 Rust translation of [WaveyCapes](https://github.com/tr7zw/WaveyCapes)
for the Horizon native-mod carrier: cape physics simulation, wind modes,
support integrations (Ears, MinecraftCapes, Wynntils, LabyMod cloak,
Shoulder Surfing, PlayerAnimator), the config screen and the
CustomCapeRenderLayer render path, translated source-for-source.
